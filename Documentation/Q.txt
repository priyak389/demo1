QuerySet Filter
The filter() method is used to filter your search, and allows you to return only the rows that matches the search term.

mydata = PetProduct.objects.filter(prodName='Ro').values()

 


Q Objects in Django
The Django Q object (django.db.models.Q) is a container for keyword arguments. 
It is primarily used for complex queries that require logical operations. The keyword arguments are encapsulated by the 
Q object and passed to query methods such as filter, exclude, and get. Multiple Q objects can be combined using the
 AND, OR, or NOT operators.
